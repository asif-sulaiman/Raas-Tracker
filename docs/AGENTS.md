# Agent Rules — pointer

**The live agent rules are at [`../AGENTS.md`](../AGENTS.md)** (repo root, so opencode
auto-loads them every session).

Edit `AGENTS.md` at the root. This file exists only to satisfy the guidebook's
`docs/` layout; it is intentionally not a copy.

## Where the rest of the documentation lives

| File | Purpose |
|---|---|
| `../AGENTS.md` | Agent rules — workflow, code standards, security, off-limits, git |
| `PRD.md` | What the product is, who it serves, scope and non-goals |
| `SPEC.md` | How it is built — stack, schema, API surface, env vars, risks |
| `plan.md` | What is done, what is next, in vertical slices |
| `handoff.md` | Written at the end of a session so the next one starts informed |

All four are **living documents**. When a new plan changes scope, architecture, or
roadmap, they get updated in the same task as the code — not in a later cleanup.
